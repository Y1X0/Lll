# MFAF — Experiment Catalogue (EXP-001 .. EXP-010)

كل تجربة معرّفة برمجيًا في `mfaf/experiments.py` (هدف/متطلبات/إعداد/إجراء/ملاحظات
متوقّعة/أدلّة/مقاييس/حدود/تكرار). ملخّص:

| Code | Objective |
|------|-----------|
| EXP-001 | تحديد هوية الجهاز من البيانات المتاحة شرعيًا (غير المتاح = null) |
| EXP-002 | رصد حالة اتصال/فصل USB (رصد فقط) |
| EXP-003 | مقارنة مقفل/غير مقفل عبر مؤشّرات شرعية |
| EXP-004 | سلوك فشل المصادقة المضبوط (قياس) |
| EXP-005 | قياس تحديد المعدّل (rate limiting) |
| EXP-006 | قياس حالة الإغلاق (lockout) |
| EXP-007 | مقارنة الحالة قبل/بعد إعادة الإقلاع |
| EXP-008 | سلامة اقتناء الأدلّة (تجزئة + تحقّق) |
| EXP-009 | إعادة بناء الخطّ الزمني |
| EXP-010 | اختبار قابلية التكرار (الحتمية) |

استعراض التعريفات: `python3 -m mfaf.cli experiment defs`.
