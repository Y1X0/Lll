# تحليل إشارة مفتاح الريموت (RF Signal Analysis) — 433.92 MHz

**الحالة:** Phase RF · جزء من [منصّة البحث الأمني](../README.md) · موجّه لمشروع تخرّج

---

## ⚖️ النطاق والحدود (اقرأه أولًا)

هذا العمل **تمرين معالجة إشارات رقمية (DSP)** على مفتاحك أنت، لأغراض تعليمية وبحثية.

| ✅ ضمن النطاق (هذا ما نبنيه) | ❌ خارج النطاق تمامًا |
|---|---|
| التقاط **استقبال فقط** لإشارة مفتاحك الخاص | **إعادة الإرسال (Replay)** لأي إشارة |
| فكّ تضمين OOK/ASK إلى بتات | **التشويش (Jamming / RollJam)** |
| استخراج النبضات والترويسة والبنية | **كسر Rolling Code** لتشغيل مركبة |
| رسم مخطط زمني للتقرير | أي إرسال على الهواء |
| شرح *لماذا* لا يعمل الـ Replay علميًا | استخدام ضد مركبة لا تملكها |

### ملاحظات قانونية وتقنية جوهرية
1. **الاستقبال فقط.** RTL-SDR جهاز استقبال لا يرسل. لو استخدمت HackRF (يرسل)، **لا تفعّل الإرسال** —
   الإرسال على 433 MHz منظّم قانونيًا ويتطلب ترخيصًا، والتشويش جريمة في معظم الولايات القضائية.
2. **Rolling Code يهزم الـ Replay بالتصميم.** مفاتيح السيارات الحديثة (KeeLoq/Hitag وأمثالها) ترسل
   **كودًا متغيّرًا كل ضغطة**. لذلك التقاط الإشارة **لا يفتح السيارة** — وهذا **استنتاج علمي قيّم لتقريرك**،
   لا عائقًا. مشروعك يوثّق البنية ويشرح آلية الحماية، لا يكسرها.
3. **العزل.** اعمل على مفتاحك على طاولة، بعيدًا عن أي مركبة، وبيئة مفصولة عن الشبكة.

> إن كان هدف المشروع فهم كيف تُحمى مفاتيح السيارات وتحليل إشارتها برمجيًا — فهذا مشروع ممتاز.
> إن انزلق نحو "كيف أفتح سيارة" — فهو يخرج عن نطاق ما أساعد فيه، وعن نطاق أي مشروع أكاديمي جاد.

## خطّ المعالجة (Pipeline)

```
[مفتاح الريموت]  ──بثّ 433.92MHz──►  [RTL-SDR / HackRF (استقبال)]
                                              │
                                    ┌─────────▼──────────┐
                                    │ 1. capture_rtlsdr  │  ضبط التردد + التقاط IQ خام
                                    │    → signal.iq      │  (complex64)
                                    └─────────┬──────────┘
                                    ┌─────────▼──────────┐
                                    │ 2. ook_decode      │  المقدار → إزالة DC → ترشيح
                                    │                    │  → عتبة تكيّفية → RLE للنبضات
                                    │                    │  → تقدير ساعة الرمز → بتات
                                    │    → bits, pulses   │  → كشف الترويسة (Preamble)
                                    └─────────┬──────────┘
                                    ┌─────────▼──────────┐
                                    │ 3. plot_timing     │  مخطط زمني للنبضات + البتات
                                    │    → timing.png     │  (دليل للتقرير)
                                    └────────────────────┘
```

## الملفات

| الملف | الدور |
|---|---|
| [`code/capture_rtlsdr.py`](code/capture_rtlsdr.py) | التقاط IQ خام (استقبال فقط) وحفظه بصيغة موحّدة |
| [`code/ook_decode.py`](code/ook_decode.py) | فكّ تضمين OOK/ASK كامل: ترشيح، عتبة تكيّفية، استخراج نبضات، تقدير ساعة الرمز، بتات |
| [`code/plot_timing.py`](code/plot_timing.py) | مخطط زمني للنبضات جاهز للتقرير |
| [`code/requirements.txt`](code/requirements.txt) | الاعتماديات |

### تشغيل سريع
```bash
pip install -r code/requirements.txt
# 1) التقاط (اضغط زر المفتاح أثناء التشغيل)
python code/capture_rtlsdr.py --freq 433.92e6 --rate 2.048e6 --seconds 3 --out signal.iq
# 2) فكّ التضمين
python code/ook_decode.py signal.iq --rate 2.048e6 --report
# 3) رسم المخطط الزمني للتقرير
python code/plot_timing.py signal.iq --rate 2.048e6 --out timing.png
```

## تصحيحات على الكود الأصلي المقترح

| المشكلة في الكود الأصلي | التصحيح |
|---|---|
| `np.fromfile(..., dtype=np.complex64)` يفترض صيغة واحدة | **RTL-SDR الخام = uint8 متداخل** (I/Q، إزاحة 127.5). دعمنا uint8/int8/complex64 مع كشف تلقائي |
| عتبة ثابتة `0.1` هشّة جدًا | **عتبة تكيّفية** من أرضية الضوضاء + ذروة الإشارة (منتصف بينهما، أو Otsu) |
| بلا ترشيح — بتات مشوّشة | **مرشّح مقدار** (متوسّط متحرّك/منخفض التمرير) قبل العتبة |
| العتبة تعطي عيّنات لا بتات | **RLE لعرض النبضات + تقدير ساعة الرمز** ثم استخراج البتات الفعلية |
| بلا معدّل عيّنات | يُمرّر `--rate` لتحويل العيّنات إلى زمن حقيقي |
| بلا كشف ترويسة | كشف الـ Preamble لتمييز الإطار عن الضوضاء |
| بلا ترميز رمزي | كشف تلقائي PWM مقابل Manchester (شائعان في المفاتيح) |
