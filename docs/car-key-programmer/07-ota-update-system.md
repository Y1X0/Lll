# 07 — نظام التحديث (OTA)

## 1. المعمارية

```
┌────────────┐    ┌──────────────┐    ┌───────────────┐    ┌─────────────┐
│  Build CI  │───►│ Signing HSM  │───►│ Update Server │───►│  CDN        │
│ (GitHub)   │    │ (مفاتيح خاصة │    │ (Go)          │    │ (تسليم)      │
└────────────┘    │  معزولة)      │    └───────┬───────┘    └──────┬──────┘
                  └──────────────┘            │ mTLS               │ HTTPS
                                     ┌────────▼────────┐           │
                                     │  MIFTAH App     │◄──────────┘
                                     │  (Flutter)      │
                                     └────────┬────────┘
                                              │ BLE / USB (موقّع من طرف لطرف)
                                     ┌────────▼────────┐
                                     │  VCI Firmware   │
                                     │ (A/B partitions)│
                                     └─────────────────┘
```

**قرار رئيسي:** الجهاز **لا يتصل بالإنترنت مباشرة.** التطبيق ينزّل الحزمة الموقّعة ويمرّرها للجهاز.
- ✅ يوفّر مودم LTE (18–25 USD/وحدة) وشريحة اتصال
- ✅ يقلّص سطح الهجوم على الجهاز إلى الصفر تقريبًا
- ✅ التوقيع من طرف لطرف يعني أن التطبيق لا يستطيع التلاعب بالحزمة حتى لو اختُرق الهاتف

## 3. سلسلة الثقة

```
Root Key (Ed25519, بلا اتصال، في HSM/خزنة، نسختان احتياطيتان)
   │  يوقّع (صلاحية 10 سنوات)
   ├─► Firmware Signing Key   ──► تُدمج نسختها العامة في Secure Boot v2 للـ ESP32
   ├─► Data Signing Key       ──► مدمجة في الفيرموير والتطبيق
   └─► Revocation Key         ──► لإبطال المفاتيح المخترقة
```

### تنسيق حزمة الفيرموير
```
┌──────────────────────────────────────────────────────┐
│ MAGIC 'MFTH' │ hdr_ver │ fw_version(semver) │ hw_rev  │
│ build_time   │ payload_len │ payload_sha256          │
│ min_prev_ver │ rollback_counter │ flags               │
├──────────────────────────────────────────────────────┤
│ Ed25519 signature over the whole header + payload    │
├──────────────────────────────────────────────────────┤
│ Payload (مضغوط + مشفّر بمفتاح خاص بالجهاز عند الحاجة) │
└──────────────────────────────────────────────────────┘
```

### التحقّق على الجهاز (بهذا الترتيب، وأي فشل ⇒ رفض)
1. `MAGIC` و `hdr_ver` صحيحان
2. `hw_rev` يطابق مراجعة العتاد
3. التوقيع صحيح مقابل المفتاح العام المخزَّن في eFuse
4. `payload_sha256` يطابق
5. `rollback_counter >= counter` المخزَّن في eFuse (**منع الرجوع لإصدار مثقوب**)
6. `fw_version > current` أو علم `FORCE_DOWNGRADE` موقّع صراحةً
7. **الجهاز غير متصل بمركبة** (فحص جهد OBD)

## 4. A/B Partitioning والتراجع

```
┌────────┬──────────┬──────────┬──────────┬───────────┐
│ bootl. │ ota_0    │ ota_1    │ nvs      │ otadata   │
│ (مقفول)│ (نشط)    │ (احتياطي)│ (إعدادات)│ (المؤشّر)  │
└────────┴──────────┴──────────┴──────────┴───────────┘
```
1. اكتب الصورة الجديدة في القسم غير النشط
2. تحقّق من التوقيع والتجزئة **بعد الكتابة**
3. علّم القسم `PENDING_VERIFY` واعِد التشغيل
4. **الفيرموير الجديد يجب أن يستدعي `mark_valid()` خلال 60 ثانية** بعد اجتياز الفحص الذاتي
5. إن لم يفعل (انهيار/تعليق) ⇒ **الـ bootloader يعود تلقائيًا للقسم القديم**

**النتيجة: من المستحيل عمليًا "تطويب" (bricking) الجهاز بتحديث فاشل.** هذا مطلب تجاري وليس تقنيًا فقط —
جهاز متوقّف = فنّي خسر يوم عمل = عميل خسرناه.

## 5. إصدار البيانات (Vehicle DB)

- **Semver:** `MAJOR` = تغيير مخطّط (يتطلب تحديث تطبيق)، `MINOR` = تنويعات/إجراءات جديدة، `PATCH` = تصحيحات
- **Delta:** يرسل الخادم فرقًا بين إصدار الجهاز وأحدث إصدار
- **قنوات:** `internal` → `beta` (10–20 فنّيًا متطوّعًا) → `stable`
- **إبطال فوري:** إن اكتُشف إجراء يُتلف وحدة، تُدفع حزمة عاجلة تضع حالته `BLOCKED`،
  والتطبيق يرفض تنفيذه حتى بلا اتصال (تُخزَّن قائمة الإبطال محليًا)
- **العمل بلا إنترنت:** التطبيق يعمل كاملًا بآخر حزمة محلية؛ فقط `OEM_PASSTHRU` و `REMOTE_TECH`
  و**التحقّق من الترخيص** تتطلب اتصالًا. **مهلة سماح 7 أيام بلا اتصال** ثم يدخل وضع القراءة فقط.

## 6. الأمان التشغيلي

| الخطر | الضابط |
|---|---|
| تسريب مفتاح التوقيع | مفتاح الجذر بلا اتصال في خزنة؛ مفاتيح فرعية في HSM سحابي؛ لا مفاتيح في CI |
| مطوّر مخترَق يدفع فيرموير خبيث | **توقيع الإصدار يتطلب موافقة شخصين** (two-person rule) |
| إعادة تشغيل حزمة قديمة (Replay) | `rollback_counter` في eFuse |
| خادم تحديث مخترَق | التوقيع يتم قبل الرفع؛ الخادم لا يملك مفاتيح توقيع |
| جهاز مقلّد يطلب تحديثات | مصادقة ATECC608B قبل تسليم الحزمة |
| تحديث أثناء الاتصال بمركبة | فحص جهد OBD يمنع البدء |
