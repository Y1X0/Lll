## 4. نقطة التعادل

### الثوابت السنوية (تشغيل بحدّ أدنى)
| البند | التكلفة |
|---|---|
| هندسة (2 FTE) | 74,000 |
| بناء قاعدة المركبات | 24,000 |
| سحابة وأدوات | 6,000 |
| دعم (0.5 FTE) | 11,000 |
| قانوني ومحاسبي | 6,000 |
| تسويق | 20,000 |
| **المجموع** | **141,000** |

### الحساب
- مساهمة الاشتراك/مشترك: 199 × 0.88 = **175 USD**
- مساهمة العمليات/مشترك: 420 × 0.26 = **109 USD**
- **مساهمة سنوية/مشترك: 284 USD**
- **نقطة التعادل: 141,000 ÷ 284 ≈ 497 مشترك نشط**

مع مساهمة بيع الأجهزة (224/وحدة عند النموّ):
**نقطة التعادل الفعلية ≈ 340–420 مشترك** إن كان النموّ مستمرًا.

> ⚠️ **هذه ليست أرقام الأردن وحده.** 400–500 مشترك تعني **الأردن + العراق + مصر أو السعودية.**
> **الاستنتاج الاستراتيجي: التوسّع الإقليمي ليس اختياريًا — هو شرط البقاء.**
> إن كانت الخطة الأردن فقط، فالنموذج المستدام هو **شركة خدمات (ورشة برمجة مركزية)** لا شركة منتج.
