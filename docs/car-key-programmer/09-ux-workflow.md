# 09 — تجربة الاستخدام (UX) وسير العمل

## 1. المبدأ

> **الفنّي يقف بجانب سيارة، في الشمس، ويداه متّسختان، والعميل ينتظر ويشكّك.**
> كل قرار تصميمي يخضع لهذا السياق: أزرار كبيرة، تباين عالٍ، أقل عدد نقرات، عربية أولًا،
> وأهم رسالة على الشاشة يجب أن تُقرأ في **3 ثوانٍ**.

**الهدف الزمني:** من فتح التطبيق إلى معرفة "هل أستطيع خدمة هذه السيارة وبكم؟" = **أقل من 60 ثانية.**

## 2. الرحلة الكاملة

### الشاشة 0 — البداية (تعكس الترتيب الحقيقي للعمل)
```
┌──────────────────────────────────────┐
│  مِفتاح                        ⚙  👤 │
├──────────────────────────────────────┤
│                                      │
│   ┌────────────────────────────┐     │
│   │   🔌  توصيل بالسيارة        │     │  ← الفعل الأساسي، 60% من الشاشة
│   │   (تعرّف تلقائي)            │     │
│   └────────────────────────────┘     │
│                                      │
│   ┌───────────┐  ┌───────────┐       │
│   │ 🔍 بحث    │  │ 📋 عملياتي│       │
│   │ يدوي      │  │  (3 مفتوحة)│      │
```

> ⚠️ **لا نبدأ بـ "اختر الشركة".** نبدأ بالتوصيل — لأن السيارة تعرّف نفسها.
> الاختيار اليدوي احتياطي فقط (سيارة لا تتصل، أو تسعير قبل الوصول).

### الشاشة 8 — التقرير
PDF بشعار المحل يحوي: بيانات المركبة، الإجراء المنفَّذ، نتائج الاختبار، تعهّد الملكية،
الطابع الزمني، رقم عملية فريد، رمز QR للتحقّق، وتوقيعي الفنّي والعميل.
يُشارك عبر واتساب بنقرة واحدة.

## 3. المسارات البديلة (Edge Cases) — لا تُهمَل

| الحالة | السلوك |
|---|---|
| فشل الاتصال بالسيارة | مرشد تشخيصي: تحقّق من الموصل، المفتاح في وضع ON، مصهر OBD |
| VIN غير مقروء | اختيار يدوي + تنبيه أن الدقّة ستقلّ |
| جهد البطارية منخفض | **حظر العملية** + إرشاد لتوصيل مثبّت جهد |
| انقطاع BLE أثناء العملية | الجهاز يتوقّف فورًا؛ التطبيق يحفظ الحالة ويستأنف |
| انقطاع الإنترنت | يعمل بالبيانات المحلية؛ التوثيق يُخزَّن ويُزامَن لاحقًا |
| نتيجة مخالفة للمتوقّع | نموذج إبلاغ بنقرة واحدة (يُغذّي تحسين القاعدة) |
| العميل يرفض التوثيق | التطبيق يوقف مسارات `OEM_PASSTHRU`/`REMOTE_TECH` — **بلا استثناء** |

## 4. قرارات التوطين

| القرار | السبب |
|---|---|
| **العربية هي اللغة الافتراضية**، RTL كامل | الفنّي الأردني/العربي لا يقرأ إنجليزية تقنية بطلاقة |
| المصطلحات التقنية بالعربية **والإنجليزية معًا** | «شريحة H (H-chip)» — الفنّي يعرف المصطلح الإنجليزي من الأدوات الأخرى |
| الأسعار بالدينار الأردني مع مكافئ USD | — |
| الأرقام بالأرقام العربية الغربية (0-9) | المعيار في الأردن |
| دعم إنجليزي كامل | للتوسّع الإقليمي والدولي |
| **دعم صوتي/فيديو داخل التطبيق** | كثير من الفنّيين يفضّلون الشرح المرئي على النصّي |
