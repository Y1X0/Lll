## 5. الفريق: ما ينفّذه مهندس واحد وما يحتاج فريقًا

### ✅ مهندس واحد قادر (متمرّس، بدوام كامل)
- تصميم PCB ولوحة الحماية
- فيرموير ESP32 (TWAI + K-Line + رابط المضيف)
- نواة Rust (ISO-TP + UDS + OBD)
- تطبيق Flutter أساسي
- خلفية سحابية بسيطة
**الزمن المطلوب لمهندس واحد: 14–20 شهرًا. وهذا خطر إنهاك وعامل تركّز معرفي (bus factor = 1).**

### ⚠️ يحتاج تخصّصًا إضافيًا
| المهمة | لماذا |
|---|---|
| **تصميم PCB لبيئة السيارة واجتياز ISO 7637-2** | خبرة EMC/عابرات — خطأ هنا = إتلاف وحدات العملاء |
| **بناء ملفات تعريف المركبات** | يحتاج **فنّي مفاتيح خبير**، لا مهندس. معرفة ميدانية لا تُشترى بالكود |
| **التوقيع والأمان (HSM, Secure Boot, eFuse)** | خطأ لا رجعة فيه |
| **الشهادات (CE/FCC/TRC)** | استشاري متخصّص |
| **العلبة وقالب الحقن** | مصمّم منتجات |
| **التحليل القانوني** | محامٍ أردني + استشارة دولية |
| **الاختبار الميداني** | فنّيون حقيقيون، لا مهندسون |

### التركيبة الموصى بها (2.5–4 FTE)
| الدور | النسبة | المسؤولية |
|---|---|---|
| مهندس أنظمة مدمجة | 1.0 | عتاد + فيرموير + نواة Rust |
| مطوّر تطبيقات/خلفية | 1.0 | Flutter + Go + السحابة |
| **فنّي مفاتيح خبير (استشاري)** | 0.5 | **بناء المعرفة — أهم دور غير هندسي** |
| مدير منتج / مؤسّس | 0.5–1.0 | العملاء، القانون، الشراكات، التمويل |
| مصمّم PCB للسيارات (عقد) | 0.2 | مراجعة + EMC |
| استشاري قانوني (عقد) | 0.1 | — |
